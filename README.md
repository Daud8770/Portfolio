# 👨‍💻 Daud Khan – Frontend Developer Portfolio

A modern, fully responsive, and sleek developer portfolio website built using **React.js**, **Vite**, and **Tailwind CSS**. It showcases my professional background, technical skills, featured web applications, and includes an interactive contact section.

---

## ✨ Features

- **Dynamic Hero Section:** Features a dynamic typewriter effect using `typed.js` to highlight various roles (Frontend Developer, React Developer, UI Developer, etc.).
- **Interactive Navigation Bar:** Features smooth scrolling behavior, active section tracking using `IntersectionObserver`, and a responsive mobile menu.
- **Featured Projects Grid:** Showcases real-world projects inside a clean browser mockup layout with live demo and GitHub repository links.
- **About Me Section:** A personal introduction highlighting my background as a developer based in Bhopal.
- **Skills Showcase:** Grid layout featuring technologies I work with, complete with brand icons and color themes (React, JavaScript, Tailwind CSS, Redux Toolkit, Git, etc.).
- **Contact Form:** Interactive contact section allowing visitors to easily reach out.
- **Fully Responsive:** Optimized for mobile phones, tablets, and desktop screens with a dark theme aesthetic.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend UI Library |
| Vite | Lightning-fast build tool and development server |
| Tailwind CSS | Utility-first CSS styling framework |
| Typed.js | Dynamic typewriter text animation |
| Lucide React & React Icons | Modern UI & brand vector icons |
| React Router / DOM APIs | Smooth scrolling & navigation handling |

🚀 Getting Started
1. Clone the Repository
Bash
git clone [https://github.com/Daud8770/portfolio.git](https://github.com/Daud8770/portfolio.git)
2. Navigate to the Project Directory
Bash
cd portfolio
3. Install Dependencies
Bash
npm install
4. Start the Development Server
Bash
npm run dev
Open the local development URL provided by Vite in your browser.

📦 Build for Production
To create an optimized production build, run:

Bash
npm run build
To preview the production build locally:

Bash
npm run preview
🌐 Deployment
You can deploy this portfolio easily on platforms like Vercel or Netlify:

Push your repository to GitHub.

Import the project into Vercel or Netlify.

Keep default settings (npm run build / dist) and hit Deploy.
